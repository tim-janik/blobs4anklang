# FreePATs based Vorbis Collection for Anklang

This is a collection of Ogg/Vorbis files, based on the original FreePATs
collection under the GPLv2 + composition exception license from 2006:

	FreePats is a project to create a free and open set of GUS compatible
	patches that can be used with softsynths such as Timidity and WildMidi.
	For more information please visit http://freepats.opensrc.org or join
	the mailing-list at "user at freepats dot opensrc dot org".

This collection is extracted from the Debian package:
        https://packages.debian.org/sid/sound/freepats

The Debian packages refers to this URL as the origin:
        https://freepats.zenvoid.org/SoundSets/general-midi.html
